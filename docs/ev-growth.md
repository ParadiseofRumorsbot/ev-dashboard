# EV 물량과 엑셀 연결

`index.html#sec-cell-growth`는 `data/ev_growth.json`을 읽는다. JSON은 재계산한 엑셀의 셀 값을 내보낸 스냅샷이다. 브라우저가 로컬 Excel 파일을 직접 읽거나 자동으로 동기화하지 않는다.

## 갱신

1. 엑셀에서 원자료·출처·가정을 함께 수정한다. 2026E 기준 입력은 `공개 전망·근거!N8:N9`, 공급변경 선택은 `공급변경 시나리오!B4`다.
2. Excel에서 전체 재계산 후 `기준안`을 선택해 저장한다.
3. 기존 Python 환경의 openpyxl을 사용해 `python scripts/export_ev_growth.py --workbook "수정한 엑셀 경로.xlsx"`를 실행한다. 수식 캐시가 없거나 오류이면 내보내기를 중단한다.
4. JSON과 엑셀의 셀사별 합계·시나리오를 대조하고 GitHub Pages에 배포한다.

날짜·기간·스키마가 바뀌면 내보내기 스크립트의 메타데이터도 함께 갱신한다. 기존 CAPA 원표를 변경하면 엑셀의 `CAPA·가동률` 원표도 확인 후 갱신한다. Notion 정기 동기화는 이 파일을 변경하지 않는다.

## 정의

- BEV·PHEV·EREV 차량 탑재 수요이며, 실제 셀 공장 출하량이 아니다. EREV는 원자료의 PHEV 분류를 따른다.
- 2026E는 상반기 실적 × 2. Tesla 3/Y는 2026-06-26 회사 취합 글로벌 판매 컨센서스와 기존 최근 12개월 배분을 적용한다.
- 2028·2029는 기존 최근 12개월 유지 또는 공개 전망이다. 성장률에는 기준연도와 미래연도 가정 차이가 포함된다.
- 지역 필터는 판매지역이다. CAPA 탭만 생산지역 기준이며, 미확인 생산공장을 판매지역으로 대신 채우지 않는다.
- 공개 수주 총량·설계 CAPA를 연간 출하량으로 나누어 넣지 않는다. 연도별 물량이 없는 신규 프로젝트는 미확인이다.
- BMW 전환은 기존 CATL 물량의 가상 이전 민감도이다. 확인된 Neue Klasse 2 배정량이 아니다. CATL 감소와 SDI 증가를 같은 양으로 처리한다.
- 가동률 공시·현재 추정·기존 대시보드 추정은 참고 영역에만 있다. EV 계산에는 들어가지 않는다.
- `CAPA·가동률!F8:G13`은 같은 공장 범위의 2026 연평균 EV CAPA와 대응 수요가 확인될 때 입력한다. H열의 수요/CAPA는 공시 가동률과 별도 지표다.
- 전체 성장률이 아닌 계산 대상 모델군 부분합이다. 공급사 미확인 비중은 산출된 GWh 내부의 비중이며 미산출 신규 모델을 포함하지 않는다.

개별 차종의 모델 ID와 엑셀 행 번호로 계산 근거를 추적할 수 있다. 원본 입력 파일·개인 코멘트의 실명·로컬 경로는 공개 JSON에 포함하지 않는다.
